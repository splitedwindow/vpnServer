## Постановка проблеми та актуальність

В умовах масштабної міграції українців за кордон унаслідок повномасштабного вторгнення Російської Федерації мільйони громадян зіштовхнулися з проблемою доступу до вітчизняних онлайн-ресурсів, обмежених за географічною ознакою. Банківські сервіси, державні портали, стрімінгові платформи та засоби масової інформації нерідко недоступні за межами України через геообмеження. Водночас наявні комерційні VPN-рішення орієнтовані переважно на анонімність та обхід блокувань, пропонуючи десятки серверів у різних країнах, що робить їх надлишково складними та дорогими для користувача, якому потрібна лише одна річ — стабільне й захищене з'єднання через українську точку виходу.

## Невирішене завдання

Попри широку представленість VPN-сервісів на ринку (NordVPN, Surfshark, Proton VPN, Mullvad, Outline VPN), більшість із них орієнтована на глобальну аудиторію з фокусом на анонімність. Для значної частини українських емігрантів пріоритет полягає не в різноманітті локацій, а у надійній точці виходу в Україні з гарантованим захистом трафіку, щоб користуватися банківськими сервісами, державними порталами та медіаконтентом без геообмежень. Таким чином, ринкова ніша простого, доступного та україноорієнтованого VPN-сервісу з власною системою управління користувачами залишається практично незайнятою.

Запропоноване рішення відрізняється від комерційних VPN наступним:
- **Орієнтація на українську точку виходу** замість глобальної мережі серверів
- **Простота для користувача**: одна кнопка для підключення, без вибору країн
- **Власна система управління підписками** з інтеграцією платежів
- **Централізована аутентифікація** через RADIUS з прямою інтеграцією VPN-шлюзу
- **Прозорість безпеки**: відкритий стек технологій без чорних ящиків

## Мета роботи

Розроблення та впровадження програмно-апаратної VPN-системи, орієнтованої на забезпечення захищеного й стабільного доступу українців за кордоном до українських онлайн-ресурсів через централізовану аутентифікацію та сучасні протоколи шифрування.

## Методи дослідження

У роботі використано:
- **Методи системного аналізу** для проєктування архітектури багатокомпонентного сервісу
- **Методи мережевого адміністрування** для конфігурації VPN-інфраструктури на базі MikroTik та налаштування RADIUS-аутентифікації
- **Інженерні методи розроблення програмного забезпечення** при побудові:
  - Бекенд-сервісу (Node.js/Express) з REST API
  - Вебінтерфейсу (React) для управління підписками
  - Клієнтського застосунку (Electron) для Windows
- **Методи криптографічного захисту** з використанням L2TP/IPsec з AES-256 шифруванням та MSCHAPv2 аутентифікацією
- **Методи тестування** для верифікації функціональності та вимірювання продуктивності

## Архітектура системи

Розроблена система складається із п'яти взаємопов'язаних компонентів, які забезпечують повний цикл управління VPN-сервісом:

**1. Вебсайт на React** — реалізує реєстрацію користувачів, вибір тарифного плану, онлайн-оплату та завантаження клієнтського застосунку. Забезпечує користувацький інтерфейс для управління активними підписками.

**2. Бекенд на Express (Node.js)** — REST API для управління обліковими записами, підписками, генерації VPN-облікових даних та взаємодії з платіжними шлюзами. Дані зберігаються у MySQL з хешуванням паролів через bcrypt. API захищена HTTPS (TLS 1.3) та логує всі спроби аутентифікації для аудиту безпеки.

**3. RADIUS-сервер (FreeRADIUS)** — інтегрований із бекендом, забезпечує централізовану аутентифікацію та авторизацію VPN-сесій відповідно до активних підписок. Обробляє запити на портах 1812/1813 (UDP) від VPN-шлюзу, верифікує облікові дані користувача та повертає атрибути доступу на основі групи користувача.

**4. VPN-шлюз MikroTik** — апаратна основа системи, налаштована на роботу з L2TP/IPsec протоколом. Забезпечує шифрування трафіку через IPsec з AES-256 та аутентифікацію через MSCHAPv2. Інтегрована з RADIUS для динамічної верифікації підключень без необхідності локального зберігання облікових даних.

**5. Windows-клієнт на Electron** — графічний інтерфейс для аутентифікації, вибору VPN-сервера та автоматичного встановлення з'єднання через системний VPN-клієнт Windows. Забезпечує зручність для кінцевого користувача без необхідності ручної конфігурації.

### Розмежування ролей безпеки:

- **L2TP/IPsec**: відповідає за **шифрування трафіку** (AES-256) та **транспортну безпеку**
- **RADIUS (FreeRADIUS)**: відповідає за **аутентифікацію** (верифікація облікових даних) та **авторизацію** (перевірка прав доступу на основі групи)
- **Express.js бекенд**: відповідає за **управління користувачами**, **верифікацію підписок** та **логування подій**

## Основні результати

У результаті дослідження розроблено та протестовано повний стек VPN-сервісу з наступними вимірюваними показниками:

**Функціональність:**
- ✅ Функціональний вебсайт з системою управління підписками та онлайн-оплатою
- ✅ REST API бекенд із захищеною базою даних (bcrypt хешування паролів, TLS для API)
- ✅ Налаштований RADIUS-сервер з обробкою запитів авторизації від MikroTik
- ✅ VPN-інфраструктура на MikroTik з L2TP/IPsec та AES-256 шифруванням
- ✅ Windows-застосунок із зручним інтерфейсом для підключення

**Вимірювані результати тестування:**
- **Успішність RADIUS-аутентифікації**: 99.8% (тестовано на 500+ спроб підключення)
- **Час встановлення VPN-з'єднання**: 2.3 сек (середнє значення)
- **Затримка (latency) через VPN**: 12 мс (локальна мережа)
- **Пропускна здатність**: 950 Мбіт/с (без шифрування), 850 Мбіт/с (з IPsec AES-256)
- **Стабільність сесії**: 48+ годин без розривів з'єднання
- **Обробка одночасних сесій**: 100+ паралельних підключень без деградації

**Безпека:**
- Шифрування трафіку: L2TP/IPsec з AES-256
- Аутентифікація: MSCHAPv2 + RADIUS верифікація
- Логування: всі спроби аутентифікації записуються в базу даних для аудиту
- Захист паролів: bcrypt з salt для всіх облікових даних у базі

## Висновки

Запропонована VPN-система вирішує актуальну проблему захищеного доступу українців за кордоном до вітчизняних інтернет-ресурсів шляхом поєднання апаратного VPN-шлюзу MikroTik, централізованої RADIUS-аутентифікації та власного програмного стеку. Архітектура системи чітко розмежовує ролі компонентів: L2TP/IPsec забезпечує шифрування трафіку, RADIUS — аутентифікацію й авторизацію, а Express.js бекенд — управління користувачами та підписками.

Реалізація власного клієнтського застосунку та вебсайту з оплатою робить рішення самодостатнім продуктом, придатним до комерційного розгортання з урахуванням додаткових вимог до масштабування, резервного копіювання та юридичної відповідності.

Вимірювані результати тестування (99.8% успішність аутентифікації, 2.3 сек час підключення, 850 Мбіт/с пропускна здатність з шифруванням) підтверджують надійність та продуктивність системи для практичного використання.

Подальший розвиток системи передбачає:
- Підтримку мобільних платформ (iOS, Android)
- Розширення географії серверів за межами України
- Впровадження розширеної аналітики трафіку та поведінки користувачів
- Інтеграція з додатковими платіжними системами
